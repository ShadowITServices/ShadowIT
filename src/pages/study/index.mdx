# Study

A collection of structured study programs I've built for Microsoft certifications —
day-by-day plans that pair Microsoft Learn content with hands-on lab work in a real
tenant, because a certification earned by reading alone doesn't transfer to the job.

Each plan is self-contained: a time budget, a domain-weighted schedule, a lab
environment to build before you start, and a review structure for the final stretch
before sitting the exam.

## Programs

- [SC-300: Microsoft Identity and Access Administrator](/study/sc-300) — a 30-day,
  ~75-hour program covering identity, access management, workload identities, and
  identity governance.

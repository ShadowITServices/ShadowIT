# Purview

Compliance and audit via Microsoft Purview. The unified audit log is reached through
**Exchange Online** (`Connect-ExchangeOnline`); DLP policy reporting uses the
**Security & Compliance** endpoint (`Connect-IPPSSession`) — both from the
`ExchangeOnlineManagement` module.

## Search the unified audit log

Searches the unified audit log for a set of operations over a date range — handy for
incident triage (e.g. mailbox-rule changes, role assignments, sharing events).
Read-only; needs an audit-log reader role. Note the tenant's audit retention limits how
far back you can search.

```powershell
#Requires -Version 5.1
#Requires -Modules ExchangeOnlineManagement
<#
.SYNOPSIS
    Searches the unified audit log for specified operations.
.EXAMPLE
    .\Search-AuditLog.ps1 -Days 7 -Operations 'New-InboxRule','Add-MailboxPermission'
.NOTES
    Read-only. Connect-ExchangeOnline first.
    Logs to C:\Temp\AuditSearch_<timestamp>.log
#>
[CmdletBinding()]
param(
    [int]$Days = 7,
    [string[]]$Operations = @('New-InboxRule', 'Set-InboxRule', 'Add-MailboxPermission', 'Add-Member', 'AddServicePrincipal')
)

$ErrorActionPreference = 'Stop'
$stamp   = Get-Date -Format 'yyyyMMdd_HHmmss'
$LogDir  = 'C:\Temp'
$LogFile = Join-Path $LogDir "AuditSearch_$stamp.log"
$CsvFile = Join-Path $LogDir "AuditSearch_$stamp.csv"
if (-not (Test-Path -LiteralPath $LogDir)) { New-Item -ItemType Directory -Path $LogDir -Force | Out-Null }
function Write-Log { param($m,$l='INFO')
    $line = '{0} [{1}] {2}' -f (Get-Date -Format 'yyyy-MM-dd HH:mm:ss'), $l, $m
    Write-Host $line; Add-Content -LiteralPath $LogFile -Value $line }

try {
    $start = (Get-Date).AddDays(-$Days)
    $end   = Get-Date
    Write-Log "Searching audit log $($start.ToString('yyyy-MM-dd')) to $($end.ToString('yyyy-MM-dd')) for $($Operations.Count) operation type(s)."

    # SessionCommand ReturnLargeSet pages results; loop until no more rows return.
    $all = @(); $session = [guid]::NewGuid().ToString()
    do {
        $batch = Search-UnifiedAuditLog -StartDate $start -EndDate $end -Operations $Operations `
                    -SessionId $session -SessionCommand ReturnLargeSet -ResultSize 5000
        if ($batch) { $all += $batch }
        Write-Log "Retrieved $($batch.Count) row(s) this page." -Level DEBUG
    } while ($batch.Count -eq 5000)

    $report = $all | Select-Object CreationDate, UserIds, Operations,
        @{N='Detail';E={ ($_.AuditData | ConvertFrom-Json).ObjectId }}
    $report | Sort-Object CreationDate -Descending | Export-Csv -LiteralPath $CsvFile -NoTypeInformation -Encoding UTF8
    Write-Log "Done. $($report.Count) event(s). CSV: $CsvFile"
}
catch {
    Write-Log "FAILED: $($_.Exception.Message)" -Level ERROR
    throw
}
```

## DLP policy & rule report

Lists Data Loss Prevention policies, their state and workloads, and the rules beneath
them — so you can confirm what's actually enforced. Read-only; run after
`Connect-IPPSSession`.

```powershell
#Requires -Version 5.1
#Requires -Modules ExchangeOnlineManagement
<#
.SYNOPSIS
    Reports Purview DLP policies and their rules.
.NOTES
    Read-only. Connect-IPPSSession first.
    Logs to C:\Temp\DLPReport_<timestamp>.log
#>
[CmdletBinding()]
param()

$ErrorActionPreference = 'Stop'
$stamp   = Get-Date -Format 'yyyyMMdd_HHmmss'
$LogDir  = 'C:\Temp'
$LogFile = Join-Path $LogDir "DLPReport_$stamp.log"
$CsvFile = Join-Path $LogDir "DLPReport_$stamp.csv"
if (-not (Test-Path -LiteralPath $LogDir)) { New-Item -ItemType Directory -Path $LogDir -Force | Out-Null }
function Write-Log { param($m,$l='INFO')
    $line = '{0} [{1}] {2}' -f (Get-Date -Format 'yyyy-MM-dd HH:mm:ss'), $l, $m
    Write-Host $line; Add-Content -LiteralPath $LogFile -Value $line }

try {
    Write-Log 'Retrieving DLP compliance policies.'
    $policies = Get-DlpCompliancePolicy -ErrorAction Stop
    Write-Log "Found $($policies.Count) DLP policy(ies)."

    $report = foreach ($p in $policies) {
        $rules = Get-DlpComplianceRule -Policy $p.Name -ErrorAction SilentlyContinue
        if ($rules) {
            foreach ($r in $rules) {
                [pscustomobject]@{ Policy=$p.Name; Enabled=$p.Enabled; Mode=$p.Mode; Rule=$r.Name; RuleEnabled=$r.Disabled -eq $false; BlockAccess=$r.BlockAccess }
            }
        } else {
            [pscustomobject]@{ Policy=$p.Name; Enabled=$p.Enabled; Mode=$p.Mode; Rule='(none)'; RuleEnabled=$null; BlockAccess=$null }
        }
    }
    $report | Export-Csv -LiteralPath $CsvFile -NoTypeInformation -Encoding UTF8
    Write-Log "Done. CSV: $CsvFile"
}
catch {
    Write-Log "FAILED: $($_.Exception.Message)" -Level ERROR
    throw
}
```

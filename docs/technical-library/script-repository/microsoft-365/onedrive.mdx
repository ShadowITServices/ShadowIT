# OneDrive

OneDrive for Business administration. Usage reporting uses **Microsoft Graph**;
offboarding access uses **PnP.PowerShell** against the SharePoint admin endpoint.

## OneDrive usage report

Pulls the Microsoft 365 usage report for OneDrive accounts (storage used, file count,
last activity) straight from Graph. Read-only; needs `Reports.Read.All`.

```powershell
#Requires -Version 5.1
#Requires -Modules Microsoft.Graph.Authentication
<#
.SYNOPSIS
    Exports the OneDrive usage report (per account) from Microsoft Graph.
.NOTES
    Read-only. Connect-MgGraph -Scopes 'Reports.Read.All'
    Logs to C:\Temp\OneDriveUsage_<timestamp>.log
#>
[CmdletBinding()]
param([ValidateSet('D7','D30','D90','D180')][string]$Period = 'D30')

$ErrorActionPreference = 'Stop'
$stamp   = Get-Date -Format 'yyyyMMdd_HHmmss'
$LogDir  = 'C:\Temp'
$LogFile = Join-Path $LogDir "OneDriveUsage_$stamp.log"
$CsvFile = Join-Path $LogDir "OneDriveUsage_$stamp.csv"
if (-not (Test-Path -LiteralPath $LogDir)) { New-Item -ItemType Directory -Path $LogDir -Force | Out-Null }
function Write-Log { param($m,$l='INFO')
    $line = '{0} [{1}] {2}' -f (Get-Date -Format 'yyyy-MM-dd HH:mm:ss'), $l, $m
    Write-Host $line; Add-Content -LiteralPath $LogFile -Value $line }

try {
    if (-not (Get-MgContext)) { throw 'Not connected. Run Connect-MgGraph -Scopes Reports.Read.All first.' }
    Write-Log "Requesting OneDrive usage report for period $Period."
    # The report endpoint returns CSV; capture it straight to disk.
    $uri = "https://graph.microsoft.com/v1.0/reports/getOneDriveUsageAccountDetail(period='$Period')"
    Invoke-MgGraphRequest -Method GET -Uri $uri -OutputFilePath $CsvFile
    $rows = (Import-Csv -LiteralPath $CsvFile)
    Write-Log "Done. $($rows.Count) account row(s). CSV: $CsvFile"
}
catch {
    Write-Log "FAILED: $($_.Exception.Message)" -Level ERROR
    throw
}
```

## Grant admin access to a departing user's OneDrive

During offboarding you often need a manager or IT to reach a leaver's OneDrive. This
adds a named admin as a site collection administrator on the user's OneDrive. **Changes
state** — supports `-WhatIf`. Needs SharePoint Administrator.

```powershell
#Requires -Version 5.1
#Requires -Modules PnP.PowerShell
<#
.SYNOPSIS
    Grants a secondary administrator access to a user's OneDrive for offboarding.
.EXAMPLE
    .\Grant-OneDriveAccess.ps1 -TargetUser leaver@contoso.com -GrantTo manager@contoso.com -WhatIf
.NOTES
    Changes state. Connect-PnPOnline to the -admin URL first.
    Logs to C:\Temp\OneDriveGrant_<timestamp>.log
#>
[CmdletBinding(SupportsShouldProcess, ConfirmImpact = 'High')]
param(
    [Parameter(Mandatory)][string]$TargetUser,   # The departing user (UPN).
    [Parameter(Mandatory)][string]$GrantTo        # Admin/manager to grant access (UPN).
)

$ErrorActionPreference = 'Stop'
$stamp   = Get-Date -Format 'yyyyMMdd_HHmmss'
$LogDir  = 'C:\Temp'
$LogFile = Join-Path $LogDir "OneDriveGrant_$stamp.log"
if (-not (Test-Path -LiteralPath $LogDir)) { New-Item -ItemType Directory -Path $LogDir -Force | Out-Null }
function Write-Log { param($m,$l='INFO')
    $line = '{0} [{1}] {2}' -f (Get-Date -Format 'yyyy-MM-dd HH:mm:ss'), $l, $m
    Write-Host $line; Add-Content -LiteralPath $LogFile -Value $line }

try {
    # OneDrive URL is derived from the UPN: user@contoso.com -> .../personal/user_contoso_com
    $tenantRoot = (Get-PnPTenantSite -Filter "Url -like '-my.sharepoint.com'" | Select-Object -First 1).Url
    $userPath   = ($TargetUser -replace '[@.]', '_')
    $odUrl      = "https://$((New-Object Uri (Get-PnPConnection).Url).Host)/personal/$userPath" -replace '-admin','-my'

    Write-Log "Target OneDrive: $odUrl"
    if ($PSCmdlet.ShouldProcess($odUrl, "Add $GrantTo as site collection admin")) {
        Set-PnPTenantSite -Url $odUrl -Owners $GrantTo -ErrorAction Stop
        Write-Log "Granted $GrantTo access to $odUrl"
    } else {
        Write-Log "WhatIf: would grant $GrantTo access to $odUrl"
    }
}
catch {
    Write-Log "FAILED: $($_.Exception.Message)" -Level ERROR
    throw
}
```

# Entra ID

PowerShell for administering **Microsoft Entra ID** via Microsoft Graph. Connect
first (see [Microsoft 365 — Overview & Connection](/docs/script-repository/microsoft-365/)),
then run any script in this section.

Scripts are grouped by the area of Entra they touch:

- **[Enterprise Applications](/docs/script-repository/microsoft-365/entra/enterprise-applications/)** —
  auditing and managing service principals (the apps registered in your tenant).
- **[Privileged Role Assignments](./privileged-role-assignments)** — who holds
  directory roles, permanently and through PIM, with synced and disabled
  holders flagged.

More areas (users and authentication methods, Conditional Access) will be added
here over time.
